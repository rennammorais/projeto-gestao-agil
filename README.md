# projeto-gestao-agil
# Objetivo
O NomadHub é uma plataforma de economia compartilhada e moradia flexível focada em trabalhadores remotos (nômades digitais), resolvendo o problema de aluguéis burocráticos e falta de infraestrutura nas hospedagens convencionais.

# Escopo
A plataforma permite buscar propriedades, visualizar infraestrutura (internet, espaço de trabalho), realizar reservas e processar pagamentos. Ficam de fora, nesta fase, recursos de rede social e integrações com companhias aéreas.
